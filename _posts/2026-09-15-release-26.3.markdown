---

Wilderness Bound is out now in Minecraft Java Edition! Pack your supplies and set off on an expedition into the dappled forest where the trails end and adventure begins. Seek out abandoned camps, build outposts among the poplar trees, sleep under the stars on straw beds, and share campfire stories atop cushions. Just remember that the wilderness rewards the prepared - and maps are lighter than regrets!<br>

Happy camping!<br>

**Changelog:**<br>
\* Added Dappled Forest Biome<br>
\* Added Poplar Trees<br>
\* Added fallen Poplar Trees<br>
\* Added Red Poplar Leaves, Orange Poplar Leaves, and Yellow Poplar Leaves blocks<br>
\* Added Poplar wood set<br>
\* Added Shelf Mushrooms<br>
\* Added Red Shrubs<br>
\* Added Abandoned Camp structures<br>
\* Added new Explorer Maps<br>
\* Added Cushions<br>
\* Added Straw Beds<br>
\* Added Wool Stairs and Wool Slabs for all Wool blocks<br>
\* Added Concrete Stairs and Concrete Slabs for all Concrete blocks<br>
\* Players in spectator mode can now interact with portals to teleport<br>
\* Improvements to Realms, including the ability to create and manage Invite Codes<br>
\* Added Gothic language support<br>
\* The Main Menu now has an updated background panorama showing the new Dappled Forest biome with an Abandoned Camp<br>
\* Removed fallen leaf particles from Spruce Trees<br>
\* Suspicious Stews can now be crafted with 2 of any mushroom<br>
\* Mushroom Stew can now be crafted with 2 of any mushroom<br>
\* The player icon on maps has been updated to always show the direction the player is facing<br>
\* New Villager trades, unlocked from a Villager leveling up their profession, will now update even if the player is in the process of trading with them<br>
\* Persistent mobs' random walk/swim behaviors will now deactivate when players are not nearby, in the same way as non-persistent mobs<br>
\* Replaced the current "Improved Transparency" approach with a new order-independent transparency algorithm which is expected to be much better at solving translucency issues<br>
\* Added a rebindable debug key combination "F3 + X" to toggle "Improved Transparency"<br>
\* When using a Shield together with a Hoe or a Shovel, raising the Shield will take precedence over tilling and path making<br>
\* Changed the Adventure Mode icon in the Game Mode Switcher to the Buried Treasure Map<br>
\* Improvements to performance when trying to locate structures<br>
\* Improvements to chunk generation performance<br>
